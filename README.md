# Flor de Finanzas v3.0

Gestor de finanzas personales open source para Android.

## Caracteristicas
- Balance en tiempo real con animacion de contador
- Graficos de dona y barras por categoria
- Multiples cuentas (efectivo, banco, ahorros)
- Metas de ahorro con confeti al cumplirlas
- Presupuestos mensuales por categoria
- Comparativa mes actual vs anterior
- Modo oscuro / claro con persistencia
- Exportar / Importar JSON y CSV
- 100% offline, sin publicidad, sin rastreo
- Navegacion inferior nativa con 5 pestanas
- Iconos SVG animados, sin emojis

## Descargar APK
1. Ve a la pestana **Actions** de este repositorio
2. Abre el ultimo workflow exitoso
3. Descarga el artefacto `flor-finanzas-apk`
4. Instala el APK en tu Android (activa "origenes desconocidos")
